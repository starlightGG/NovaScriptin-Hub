# NovaScriptin-Hub

A client that modifies any website of your choosing!

**Live Site:** [https://github.io](https://github.io)

---

## Quick Start

You can run NovaScriptin-Hub via a bookmarklet or directly through your browser's developer console. Visit the [NovaScriptin-Hub Script Loader](https://github.io) to grab the code for either method.

### Option 1: Bookmarklet
1. Copy the bookmarklet code from the live site.
2. Show your bookmarks bar (`Ctrl + Shift + B` on Windows/Linux or `Cmd + Shift + B` on Mac) and add a new bookmark.
3. Paste the code into the URL field, save it, and click the bookmark while on your target website.

### Option 2: Developer Console
1. Copy the console command from the live site.
2. Open Developer Tools on your target site (`F12` or `Ctrl + Shift + I` / `Cmd + Option + I` on Mac) and go to the **Console** tab.
3. Type `allow pasting` if required by your browser, then paste and execute the command.

---

## Troubleshooting (Blocked Requests / Errors)

If a website's Content Security Policy (CSP) blocks external scripts, grab the raw script (`scripts/main.js`) using the **Copy Raw** button on the [NovaScriptin-Hub Script Loader](https://github.io) and paste it directly into the target site's console.
