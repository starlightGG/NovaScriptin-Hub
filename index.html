How to Use the Bookmarklet

  1. Click the Copy Bookmarklet button below to copy commands/bookmarklet.txt to your clipboard.
  2. Show your browser bookmarks bar with Ctrl + Shift + B or Cmd + Shift + B.
  3. Right-click the bookmarks bar and select Add Page or Add Bookmark.
  4. Paste the copied code into the URL field and click Save.
  5. Open the target page and click your new bookmarklet to run it.

Getting an error or blocked request? If the loader fails as shown below, you need to click this separate button that says Copy Raw — it copies scripts/main.js directly to your clipboard so you can paste the full script into the console instead (view console instructions).

How to Use the Developer Console

  1. Click the Copy Console Command button below to copy commands/console.txt to your clipboard.
  2. Open Developer Tools on the target page with F12 or Ctrl + Shift + I and open the Console tab.
  3. If your browser blocks pasting, type allow pasting and press Enter first.
  4. Paste the copied command into the console and press Enter.
